Bonjour, moi c'est Mohamed 👋
Je suis technicien informatique à Niamey, au Niger. Je travaille à mon compte sous le nom Tout Informatique Lazaret (TIL).

Dans mon quotidien, il y a du dépannage, de l'assistance et des problèmes très pratiques à résoudre. Et, quand je peux aller plus loin, j'essaie de construire les logiciels que j'aurais aimé avoir sous la main.

Je développe depuis Niamey, j'apprends au fil des projets et je cherche surtout à faire des choses qui servent réellement.
Quelques projets
- Z-Score Niger — Un calculateur d'indicateurs de croissance avec plusieurs référentiels, utilisable en français, anglais et arabe. Code source. Ce n'est pas un dispositif médical certifié.
- PharmaTrace — Un projet expérimental de traçabilité de lots pharmaceutiques réalisé en équipe dans le cadre du MIABE Hackathon. Code source. Il ne certifie pas l'authenticité physique d'un médicament.
- Badge Access — Un projet de gestion du pointage et des accès que je développe. Son code n'est pas public.
Les applications évoluent encore. Si tu en essaies une et rencontres un problème, les formulaires de retour sont accessibles directement depuis les applications publiées.
